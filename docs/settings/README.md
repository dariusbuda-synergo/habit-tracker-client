# settings

The settings page and its localStorage-backed preferences: default weekly target, daily
reminder time, completion sound, week start day, and the theme toggle. Code:
`app/settings/page.tsx`, `app/lib/settingsPrefs.ts`, `app/components/ThemeToggle.tsx`,
`app/layout.tsx` (theme bootstrap). Note: reminder time, sound and week start are stored but
not yet acted on anywhere (`AGENTS.md § PREFS-1`).
